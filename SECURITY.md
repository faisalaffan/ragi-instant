# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

**Do not open a public issue.** Instead, please report security vulnerabilities privately:

1. Email: [security@faisalaffan.com](mailto:security@faisalaffan.com)
2. Include detailed steps to reproduce
3. Allow up to 48 hours for acknowledgment and 7 days for a fix

## Scope

Security issues may include:
- Injection vulnerabilities in document parsing
- Sensitive data exposure in retrieval pipelines
- Prompt injection vectors

## Disclosure

We follow coordinated disclosure. After a fix is released, we will:
1. Publish a security advisory
2. Credit the reporter (unless anonymity is requested)
3. Document the CVE if applicable
